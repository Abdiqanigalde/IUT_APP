# IUT Appointment System

A Flask-based university appointment booking system for IUT Dhaka.

---

## 🚀 Deploy to Render (Recommended)

### One-click setup
1. Push this repo to GitHub.
2. Go to [render.com](https://render.com) → **New** → **Blueprint** → connect your repo.
   - Render will auto-detect `render.yaml` and configure everything.
3. Set the required environment variables when prompted:
   - `BREVO_API_KEY` — **required.** Create a free [Brevo](https://www.brevo.com) account, generate an API key under SMTP & API → API Keys. This is how the app sends password-reset and email-verification mail (Render's free tier blocks outbound SMTP, so mail goes over Brevo's HTTP API, not SMTP).
   - `MAIL_USERNAME` — optional. The "from" address shown to recipients (defaults to `noreply@iut-dhaka.edu`).
4. Click **Apply** and wait ~2 minutes for the first deploy.

> `SECRET_KEY` is auto-generated by Render. The SQLite database is stored on a persistent 1 GB disk so data survives redeploys.
>
> ⚠️ If `BREVO_API_KEY` isn't set, the app still runs, but new users can never receive a verification email or a password-reset link — they'll be stuck unable to log in or recover their password. Set it before inviting real users.

### Manual setup (if not using Blueprint)
1. **New Web Service** → connect repo
2. **Build Command:** `pip install -r requirements.txt`
3. **Start Command:** `gunicorn --worker-class eventlet -w 1 --bind 0.0.0.0:$PORT app:app`
4. **Environment Variables:**

   | Key | Value |
   |-----|-------|
   | `SECRET_KEY` | any long random string |
   | `FLASK_ENV` | `production` |
   | `BREVO_API_KEY` | your Brevo API key (required for email) |
   | `MAIL_USERNAME` | the "from" address shown to recipients (optional) |

5. **Disk** → Mount Path: `/opt/render/project/src/database`, Size: 1 GB

## 💻 Local Development

```bash
pip install -r requirements.txt
python app.py
```

Visit `http://localhost:5000`

### Seed test data
```bash
FLASK_ENV=development python seed_dev_data.py
```
Creates: Admin `admin@iut-dhaka.edu / admin123` and Student `abdinadiif@iut-dhaka.edu / student123`

### Default super admin (auto-created on first run)
- Email: `superadmin@iut-dhaka.edu`  
- Password: `SuperAdmin@2026!` (you'll be forced to change this on first login)

## ✅ Running Tests

```bash
pip install -r requirements-dev.txt
pytest
```

Tests run against a throwaway temporary SQLite database (created and destroyed automatically) — they never touch your local `database/university.db` or any real data. Run a single file or test with:
```bash
pytest tests/test_auth.py
pytest tests/test_auth.py::test_login_blocked_when_email_unverified
```

---

## 🗄️ Database Migrations

```bash
flask db init && flask db migrate -m "initial" && flask db upgrade
# After any model change:
flask db migrate -m "describe change" && flask db upgrade
```

## ✨ Features
- IUT email enforcement, role-based access (Super Admin / Admin / Officer / Student)
- QR code appointment slips, live status via Socket.IO
- Email notifications, waitlist auto-promotion, analytics dashboard
- Dark mode, session timeout, rate limiting, audit logs
