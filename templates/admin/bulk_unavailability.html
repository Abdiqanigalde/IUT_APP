Note: This cancels all pending/approved appointments that fall within the affected dates for every selected officer, and notifies each student by email.
How this works
  • Single date range — every selected officer is unavailable for the entire span, e.g. an out-of-office week.
  • Recurring weekly — pick a weekday (e.g. every Wednesday) and a date range, e.g. "every Wednesday from Sep 1–Dec 15" for a standing commitment. This creates one unavailability entry per matching date, so it shows up correctly on each officer's calendar.
  • To mark every officer unavailable for a university-wide holiday, use Holidays instead — it's built for that and doesn't require selecting officers individually.
  • To manage a single officer's periods one at a time, go to their officer page and use "Manage Unavailability".
